6
DEBUG · 15 MIN

Find a realistic defect

Choose a challenge. Introduce the defect in one prompt, then start a fresh debugging conversation to reproduce and repair it.

SECURITY#101

Signature timing leak

Replace constant-time digest comparison with String#equals, then ask Copilot to find the review risk.

Inspect how the computed and provided digests are compared. Equal content is not the only security requirement.
RELIABILITY#102

Idempotency race

Replace atomic acquisition with check-then-set, then reproduce concurrent duplicate credits.

Two requests can both observe a missing key before either writes it. The fix must be one Redis operation.

Common workshop issues

Start the managed services, wait for health checks, and retry.

./scripts/dev-up.sh
401Webhook signature rejectedThe body and HMAC do not match.⌄

Sign the exact bytes sent by curl. Even whitespace or a regenerated timestamp changes the digest.

./scripts/manual-webhook-test.sh
